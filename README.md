# Olist Sales & Supply Chain Intelligence

## Project Overview
Analzying 100,000+ Brazilian e-commerce transaction recrods from Kaggle to identify top revenue drivers across customer segments and regions, while pinpointing supply chain bottlnecks and delivery delays.

## Tech Stack
* **Python**: `pandas` and `sqlalchemy` for ETL data ingenstion scripts
* **PostgreSQL**: Relational database storing the 100k+ transactions records
* **Git & GitHub**: Version control and code management

## Roadmap
* **Power BI**: Build an executive dashboard featuring geographic KPIs and shipping metrics
* **Interactive Building**: Publish the dashboard to Power BI Service with a public interactive link
